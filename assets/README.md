# 素材放这里

## can/
单件产品图，**透明底 PNG**，长边建议 ≥800px。文件名与配置里的 `can_image` 对应。

取得方式按优先级：用户上传 → 用户指定网址下载 → 拼多多后台机会商品（容量词搜索）→ 电商平台搜索（需用户扫码登录）→ 用户自有方案。

注意：
- 多件合影不能直接竖切成窄条，会切掉标签
- 邻件与主体相连时用图生图提取，提取后核对标签、容量、无糖标识没被重绘
- 带他人水印、促销压条遮挡产品的图不能用

## scenes/
场景底图，五张：`ice.png` / `fridge.png` / `desk.png` / `party.png` / `food.png`。

要求：不含产品、不含文字，中间留出产品位。可用 AI 生成空场景，生成后再把本品合成上去。
